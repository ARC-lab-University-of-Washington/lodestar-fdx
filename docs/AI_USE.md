# AI use

## Statement

AI assistance (Anthropic Claude) was used during development of this project for
code drafting, refactoring and documentation. The corpus metadata this project
consumes is LLM-distilled from OCR text and is documented as such. All released
content was reviewed and verified by the authors, who are solely responsible for
its correctness.


## Independent cross-model audit

Code drafted with one model was audited with a second, independent model (OpenAI
ChatGPT).

## Human review

Every file in this release was read by an author before inclusion.

## Reproducing the reported results

See [`REPRODUCING.md`](REPRODUCING.md) for what reproduces from the shipped
artifacts, what needs a local model, and what needs the Jetson.
